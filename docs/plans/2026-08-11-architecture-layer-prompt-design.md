# 架构分层提示词设计

## 目标

把护理信息化 16:9 实际成图中验证有效的「三层九模块、左侧层级标签、卡片对齐、双向数据流」固化为可复用规格，不再依赖调用者临时补写长提示词。

## 设计

在每个 `section` 中增加可选字符串字段 `layer`。同名层级按首次出现顺序归组。提示词生成器统计当前页面的层数、每层模块数和最大列数；在 PPT 架构图中自动写入横版行列网格、左侧层级标签、模块总数及双向数据流约束。层级标签同时进入可见文字清单，因此也接受隐私与高风险事实检查。

未填写 `layer` 的旧规格保持兼容。九模块 PPT 架构图仍自动获得 3×3 网格提示；其他版式只输出模块总数，不引入分层语义。

## 验证

新增测试覆盖层级标签去重、模块计数、行列网格、双向箭头提示、层级文本进入内容核验，以及非法 layer 类型被拒绝。继续运行全部单元测试、九案例验收和安装一致性检查。
