## 验收中发现并修复的问题

原校验器只扫描模块正文，没有扫描标题和副标题，导致副标题中的「示意数据」未进入质量报告。本次增加统一的规范文本收集逻辑，标题、副标题、模块标题和模块条目均纳入隐私与证据检查。

安装器在分支刚更新后可能获得旧的直接下载快照。安装检查器因此增加可选的 SHA-256 来源一致性检查；本次使用 Git 检出模式重新验证远程 `main`，并确认用户级安装与来源一致。
