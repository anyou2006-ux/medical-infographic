# GPT 整页直出

## 默认策略

使用图像生成模型一次生成完整页面。提示词同时包含画布、版式、视觉风格和全部可见文字；不要先生成背景再用 SVG 覆盖内容。

## 提示词构成

1. 明确渠道、比例、版式、密度和受众。
2. 列出本页所有文字，要求逐字照抄、只出现一次、不增删、不翻译。
3. 指定阅读顺序、模块数量、层级、连接方向和来源区位置。
4. 描述配色、卡片、图标、光线与材质，但让装饰服从信息层级。
5. 明确禁止水印、品牌标识、伪造界面、占位文字和清单外文字。
6. 对高密度页面要求优先保留文字；空间不足时减少装饰，不得缩成不可读小字。

架构图优先在规格中使用 `section.layer` 表达层级。提示词生成器会自动写出层数、每层模块数、横版网格和双向数据流，避免临时手写结构说明。

运行：

```text
python scripts/build_gpt_prompt.py infographic-spec.json --output-dir artifacts/example
```

将生成的 `gpt-prompt-01.txt` 原样提交给内置图像生成工具。多页内容每次只生成一页，避免页面之间串字或风格漂移。

## 逐页核验

使用图像查看工具放大检查：

- 标题、模块名和正文是否与规格一致；
- 数字、单位、日期和来源是否准确；
- 是否出现乱码、同音错字、漏字、重复字或模型新增文字；
- 箭头方向、模块分组和阅读顺序是否正确；
- 页面比例、裁切、安全边距和投影可读性是否合格。

第一次失败时，只描述一个最重要的问题并重试该页，同时重申「其他内容保持不变」。第二次仍失败时，优先减少单页文字或拆页；不得通过后期覆盖关键文字伪装通过。

## 降级条件

只有以下情况允许切换到混合或 SVG：

- 当前环境没有图像生成工具；
- 用户显式要求可编辑矢量文件；
- 同一页连续两轮出现不可接受的中文或数字错误。

降级时在最终回复和 `quality-report.json` 中写明原因。
