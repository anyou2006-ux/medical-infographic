# 混合渲染（降级路径）

默认使用 [gpt-rendering.md](gpt-rendering.md) 的 GPT 整页直出。本文件仅在图像工具不可用、用户要求可编辑 SVG，或 GPT 连续两轮文字校验失败时使用。切换前告知用户并记录原因。

## 桌面端完整模式

1. 先确定 `infographic-spec.json`，再生成视觉素材。
2. 调用可用的图像生成工具，只生成背景、人物、设备、空间和装饰元素。
3. 在提示词中要求「无文字、无数字、无水印、留出排版空间」。
4. 将生成的 PNG 路径写入 `visual_asset`。
5. 使用 `render_svg.py` 将视觉素材作为低透明度背景，叠加确定性文字和图表。
6. 使用 `render_png.cjs` 导出 PNG。
7. 查看最终图片，检查对比度、裁切、错位和视觉噪声。

## CLI/IDE 降级模式

缺少图像生成工具时，不阻塞 SVG 输出。使用主题色、卡片、线条和基本几何图形完成纯 SVG 信息图，并在质量报告中写入 `render_mode: svg`。

## 图像提示词边界

提示词应描述视觉对象、构图、光线、材质、色彩和留白。不要要求图像模型生成：

- 长段中文；
- 表格、坐标轴或复杂图例；
- 政策原文与关键数字；
- 医院或厂商排名；
- 患者信息与真实病历界面。
