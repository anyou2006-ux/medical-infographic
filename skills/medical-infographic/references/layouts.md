# 版式选择

| 版式 | 适用内容 | 结构限制 |
|---|---|---|
| `architecture` | 系统分层、模块关系、数据流 | 3—9 个模块；连接方向必须明确 |
| `workflow` | 门诊、护理、药品、手术等业务流程 | 3—10 个连续步骤；每步使用动宾短语 |
| `timeline` | 政策、建设阶段、技术演进 | 3—12 个时间节点；日期口径保持一致 |
| `matrix` | 标准、方案、技术路线对比 | 微信端最多 3 列；宽表拆页 |
| `dashboard` | 运营、质量、成本指标 | 只展示有来源的指标；不生成随机仪表数值 |
| `anatomy` | 智慧病房、设备、平台能力解剖 | 一个核心对象与 2—6 个外围模块 |

## `auto` 选择规则

1. 出现「步骤、阶段、流程、办理」时选择 `workflow`。
2. 出现连续年份、季度或版本演进时选择 `timeline`。
3. 出现方案对比、厂商对比或多维评价时选择 `matrix`。
4. 出现 KPI、运营指标或实时监控时选择 `dashboard`。
5. 出现设备部件、病房设施或核心对象拆解时选择 `anatomy`。
6. 其他系统模块与数据关系选择 `architecture`。

无法在两个候选版式之间可靠判断时，给出推荐版式并提出一个简短问题。
